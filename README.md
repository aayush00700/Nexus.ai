# 🚀 Nexus.ai – AI-Powered Shorts Generator from YouTube Videos

**Nexus.ai** is a powerful web application built using **React.js**, **Tailwind CSS**, **JavaScript**, **Python**, **Firebase**, and **LLama API**, designed to help creators automatically generate engaging short-form video content from long YouTube videos. It identifies and extracts the most viral-worthy clips and provides everything needed to upload them as high-performing content on platforms like **Instagram Reels**, **YouTube Shorts**, and **TikTok**.

🔗 **Live Demo**: [https://aayush00700.github.io/Nexus.ai](https://aayush00700.github.io/Nexus.ai)

## 🧠 Features

- 🔐 **User Authentication** – Sign up and login with Firebase Auth
- 🎥 **YouTube Integration** – Paste a YouTube URL to begin
- ✂️ **Shorts Extraction** – AI analyzes and cuts the best viral moments
- 🧠 **Subtitles & Captions** – Auto-generated and downloadable
- 📝 **AI-Generated Metadata**:
  - Viral score
  - Keywords
  - Video description
  - Suggested title
- 📥 **Downloadable Clips** – Export shorts instantly
- 💳 **Razorpay Integration** – (Optional) Monetization/payment support
- 💌 **SMTP Email System** – Notifications and support

## 🛠 Tech Stack

- **Frontend**: React.js, Tailwind CSS, HTML, JavaScript
- **Backend**: Python (REST API)
- **AI & NLP**: LLama-based models for content analysis
- **Authentication & DB**: Firebase
- **Payments**: Razorpay
- **Email Notifications**: SMTP Integration
